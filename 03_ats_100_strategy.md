## 🔍 WHAT IS ATS AND HOW IT SCORES YOU

ATS software (used by Naukri, LinkedIn, Greenhouse, Lever, Workday) does this:
1. Parses your resume into plain text
2. Extracts: Skills / Job Titles / Education / Experience Keywords
3. Matches against the Job Description (JD)
4. Scores 0–100 — below 60 = auto-rejected

**The secret:** ATS doesn't understand context. It counts **exact keyword matches**.

## ✅ ATS MASTER CHECKLIST — 100 SCORE FORMULA

### 📄 FORMAT (25 points)
- [x] Use `.docx` format — NOT PDF (PDFs often break ATS parsing)
- [x] NO tables, NO columns, NO text boxes — ATS can't read them
- [x] NO headers/footers — ATS ignores them
- [x] Standard fonts only: Arial, Calibri, Times New Roman
- [x] File name: `ArunPandian_DataAnalyst_Resume.docx`
- [x] Margins: 0.5–1 inch
- [x] No graphics, icons, or images

### 📌 SECTION HEADERS (Use Exactly These) (15 points)

```
SKILLS
WORK EXPERIENCE
EDUCATION
CERTIFICATIONS

```
> ⚠️ Do NOT use creative headers like "My Journey" or "What I Do"
> ATS only recognizes standard section headers.

## 🎯 JOB-SPECIFIC ATS CUSTOMIZATION (CRITICAL)

**For EVERY job you apply to, do this 5-minute customization:**

1. Open the JD → Copy all text
2. Open your resume → Find 5 keywords from JD not in your resume
3. Add them naturally into your bullets or skills
4. Run through Jobscan → aim for 80%+ match
5. Save as `ArunPandian_[CompanyName]_DataAnalyst.docx`

**Example: If applying to Zoho:**
- JD says: "CRM analytics, SaaS metrics, funnel analysis"
- Add to your projects: "Conducted funnel analysis on SaaS user data..."
